# bharatkavach-1005
Bharat Kavach

Project Description  
Bharat Kavach is an all-in-one safety and emergency response web application designed to provide instant help, family safety tracking, and AI-powered assistance during critical situations.

---

Features  
- SOS Emergency Alert System  
- Family Safety Management  
- Emergency Services Directory  
- Government Emergency Contacts  
- Investigation Hub  
- AI Command Center (Suraksha AI)  
- Settings and Smart Profile  

---

Tech Stack  
- HTML  
- CSS  
- JavaScript (Vanilla)  
- LocalStorage (for data persistence)  

---

Setup Instructions  
1. Download or clone the repository  
2. Open index.html in your browser  
3. The application runs instantly (no installation required)
